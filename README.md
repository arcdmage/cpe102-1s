# The requirements for this project are as follows;
- Main Menu – Start Game, Instructions, and Exit.
- Game Objective – A clearly defined goal for the player.
- Player Interaction – Keyboard-based user input.
- Scoring System – Points earned or lost based on gameplay.
- Game Conditions – Clearly defined winning and losing conditions.
- Loops – Used appropriately for continuous gameplay.
- Conditional Statements – Used for game decisions and events.
- Functions – At least 3 user-defined functions.
- Arrays – At least one array used meaningfully.
- Input Validation – Invalid inputs must be handled properly.
- Game Over/Restart – Players can restart or return to the main menu.
- Source Code Submission – Submit the .cpp file and any required supporting files.
- Documentation – Brief explanation of the game, objectives, rules, algorithms/flowchart, and C++ concepts used.
- Group Presentation - each group should present their C++ game within 5-10 minutes of slides presentation.
